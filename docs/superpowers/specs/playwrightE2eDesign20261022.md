# Playwright E2E 设计

## 目标

在 Toonflow 仓库中引入 Playwright Test，并把已确认的桌面端完整主链路整理为可重复执行的浏览器端到端用例。默认不访问真实 SXWZ 账号或付费模型服务。

## 执行环境

- 使用仓库根目录的 Playwright Test，统一驱动 Web、Server 与 Linux 桌面桥接联调栈。
- 先覆盖 Linux Chromium 桌面桥接模式：`/?desktop=1`；测试通过 `bun run dev` 所启动的实际应用栈运行。
- 每次运行使用独立临时数据目录、工作区及 Web/Server/SXWZ 替身端口，不读取、覆盖或清理用户当前的 `data/` 设置及 `linuxDevWorkspace`，也不复用或停止开发者当前的服务。
- Playwright 启动一个本地 SXWZ 协议替身服务。应用仍经真实本地 Server 走登录、模型目录、模板读取和媒体生成请求；替身只在外部服务边界返回确定性响应。
- 生成用例使用运行时合成的无敏感 PNG；替身只返回测试结果，不调用真实模型、不产生算力费用。
- 用例串行运行，避免共享 Server 会话和本地测试数据相互竞争。失败时保留 Playwright trace、截图和报告，输出目录加入 Git 忽略。

## 用例范围

1. **桌面启动与首页**：完成本地桌面初始化；首页显示项目列表且没有创作输入框；桌面连接状态接口返回 200（服务端桌面模式提供本机连接状态）。
2. **项目往返**：打开测试工作区、从工作区返回首页、从项目列表重新打开；检查项目列表状态与路由。
3. **画布持久化**：创建一个可用节点，等待画布保存，重新载入或重开项目后确认节点仍在。
4. **媒体模型设置**：打开“设置 → 媒体模型”，确认页面没有意外整页重载，SXWZ 供应商标题显示为“SXWZ算力”；通过不同模型模板覆盖参数 schema 联合支持的字段类型，每个模型只显示自身模板声明的字段，并覆盖文生图与图片编辑能力。
5. **图片输入生成**：通过真实页面上传合成参考图到隔离工作区；本地 Server 读取工作区相对路径对应的图片并向 SXWZ 替身提交 Base64；检查适用请求的 `platform_code` 为 `toonflow`；替身通过本地 HTTPS 结果端点返回图像后确认画布显示生成结果。
6. **模型读取失败**：让 SXWZ 替身分别返回超时/无效模板响应，确认页面呈现错误、应用仍可操作，并检查服务端持久化诊断日志包含模型标识和字段校验路径但不包含凭证或完整 hidden default。

## 结构与命令

- `playwright.config.ts`：Chromium、桌面视口、串行执行、服务启动、超时及失败产物配置。
- `e2e/`：按用户流程拆分 Playwright 测试文件，文件名使用小驼峰，例如 `projectFlows.spec.ts`、`mediaModelFlows.spec.ts`。
- 测试替身和运行期合成素材只放在 E2E 目录，不进入产品代码或真实工作区。
- 根 `package.json` 提供显式 E2E 命令；首次运行按 Playwright 提示单独安装 Chromium。当前不接入 CI，也不把安装/测试绑定到开发、构建命令。
- 更新 `AGENTS.md` 的测试边界，只为本次批准的 Playwright E2E 套件增加明确例外；其他测试框架、单元测试和业务源码内的自检仍不增加。

## 不包含

- 不测试真实 SXWZ 登录凭证、真实算力任务、线上收费、生产账户状态或真实 OSS。
- 本轮不覆盖 Windows/macOS 原生窗口与安装器，不枚举每个节点、每种模型字段组合或全部设置项。
- 不新增 CI 工作流，不改变产品运行时校验和现有外部服务接口。

## 验收标准

- 从新建的隔离测试数据运行时，Playwright 能自行启动桌面联调栈并执行上述用例。
- 用例验证真实浏览器、真实前端与本地 Server 的交互；外部服务由本地协议替身隔离。
- 替身覆盖不同模型参数类型、文生图/图片编辑能力和图片上传参数，断言 schema 并集、图片 Base64 传递及 `platform_code=toonflow`。
- 测试结束不会修改开发者原有数据，所有默认用例均不会触发真实外部服务或付费调用。
- 失败报告能够定位步骤，并可查看对应 trace 或截图。
